# PhysDec

Project page for **Decompose, Verify, Evolve: Physically Grounded Shape Decomposition**.

Wenchao Ma\*, Rui Yu\*, Fan Zhu, Jiachen Liu, and Sharon X. Huang.  
\* Equal contribution.

**Website:** https://wenchao-m.github.io/PhysDec/

This repository contains the static project page and its demonstration assets.
GitHub Pages publishes the root of the `main` branch; `.nojekyll` keeps the assets unchanged.

To preview locally, run `python3 -m http.server 8765` from this directory.
